# ADR-070: Mobile Responsive Layout for Dashboard

**Status:** Accepted  
**Date:** 2026-07-01  
**Context:** The Pipshed dashboard (`templates/dashboard.html`) had zero `@media` queries. Fixed-column grids (`.grid` at 2 columns, `.grid-3` at 3 columns) never collapsed on narrow viewports. On mobile, three pod cards and related content were squeezed into a fraction of the screen width with no wrapping or stacking, causing labels, instance buttons, and quote/exposure rows to compress and wrap badly.

## Decision

Append a single additive `@media (max-width: 640px)` block as the last rule inside the existing `<style>` section. No existing CSS rules, HTML markup, JavaScript, viewport meta tag, or backend/telemetry logic are modified.

### Breakpoint: 640px

Standard mobile/tablet boundary. Viewports wider than 640px retain the pre-change desktop layout unchanged — every override is guarded by `max-width: 640px`.

### Rules inside the media block

| Selector | Change |
|----------|--------|
| `.grid`, `.grid-3` | `grid-template-columns: 1fr` — single-column stack |
| `.card` | Reduced padding (`14px 16px`) |
| `.instance-bar` | `flex-wrap: wrap` |
| `.instance-btn` | Flexible sizing, centered text, `white-space: nowrap` |
| `.quote-row`, `.macro-exposure-row` | Column layout, left-aligned, small gap |
| `.quote-spread` | `align-self: flex-end` |
| `body` | Reduced padding (`12px`) |

## Consequences

- **Positive:** Pod cards, equity row, instance selector, and aggregate widgets stack cleanly on mobile.
- **Positive:** Desktop appearance (> 640px) visually identical to before — additive override only.
- **Positive:** Presentation-only; no data, API, or telemetry changes.
- **Neutral:** Further breakpoints (e.g. tablet-only 641–900px) out of scope unless a follow-up ADR is needed.
