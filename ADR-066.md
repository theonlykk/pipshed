# ADR-066: Cross-Instance Best Working Quotes on Aggregate Endpoint

**Status:** Accepted  
**Date:** 2026-07-01  
**Context:** ADR-065 added `/api/telemetry/aggregate` for net exposure and system alerts. Operators also need a cross-instance view of resting quote prices without pulling three full live payloads or changing EA telemetry shape.

## Decision

### 1. Extend aggregate endpoint with `best_quotes`

Add `best_quotes` to the existing `GET /api/telemetry/aggregate` response alongside `net_exposure`, `system_alerts`, and `instance_status`.

For each symbol, scan `working_orders` from all three instances (`MM`, `SNIPER_LONG`, `SNIPER_SHORT`) and compute:

- **`best_bid`:** maximum resting `bid_price` across instances (best price to sell into)
- **`best_offer`:** minimum resting `offer_price` across instances (best price to buy from)

Symbols with no resting order on one or both sides retain `null` for that side. Missing or `null` bid/offer values are skipped — no crash when only one side is quoted.

**Data source:** Reuses the existing `working_orders` field already present in per-instance Redis state. No EA-side changes required.

### 2. Dashboard widget

Add a **Best Working Quotes (All Instances)** card immediately after the Macro Exposure card (between `#pod-grid` and Row 3 engine state). Populated by appending to `renderAggregate()` in the same 5-second poll cycle as banner and macro exposure.

Spread display: `(best_offer - best_bid) / 0.0001`, formatted as pips with one decimal.

**Pip assumption:** Fixed divisor `0.0001` for all symbols in the current triad. No JPY-aware logic — out of scope (no JPY pairs in this triad).

### 3. Interpretation caveat — negative or inverted spread

A negative spread reading on this aggregate widget does **not** necessarily indicate a crossed book or latency fault on any single instance.

Each pod manages its own quote independently; bid/offer on any one instance remain internally correctly ordered. The aggregate combines **independently-managed pods quoting inward of each other across instances** — e.g. MM's best bid and SNIPER's best offer may overlap when viewed together even though neither instance's own book is crossed.

**Do not** treat this widget as a reliable arbitrage or latency alert signal without that caveat. It is an informational cross-instance price snapshot, not a single unified order book.

## Consequences

- **Positive:** Operators see cross-instance quote extremes in one lightweight poll; no new telemetry fields on push.
- **Positive:** Existing aggregate keys and frontend banner/macro logic unchanged — additive only.
- **Negative:** Aggregate spread can be misleading without the multi-instance interpretation caveat above.
- **Negative:** 0.0001 pip divisor is wrong if JPY pairs are ever added to the triad without a follow-up ADR.

- `templates/dashboard.html` — quotes card, CSS, `renderAggregate()` extension
